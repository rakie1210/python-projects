# Python Mini Projects

A series of small projects in Python, inspired by Udemy's **100 Days of Code in Python** course.

Each project is a short, self-contained exercise built to practice a specific concept, from the basics (variables, loops, functions) to more advanced topics (OOP, working with APIs, data analysis, and more).

## About this repo

- One folder per project, each runnable on its own
- Small in scope, focused on learning by building
- Written and kept here as a record of my progress with Python

> This repo is an independent learning portfolio and is not affiliated with or endorsed by Udemy or the course instructor.

## Projects

| Project | Description |
|---------|-------------|
| [quiz-game](./quiz-game) | A python project that creates multiple classes and methods. This is a game where user needs to answer True or False |
| [turtle-graphics](./turtle-graphics) | A project to create an artwork using turtle graphics module. |
| [hirst-painting](./hirst-painting) | A project that recreates a Hirst Spot Painting using colorgram and turtle graphics.|
| [etch-a-sketch-app](./etch-a-sketch-app) | A project that recreates the classic toy Etch-a-sketch where you can draw using the keyboard keys.<br/> This is learning about Higher Order Functions and Event Listeners in Python.|
| [turtle-race-game](./turtle-race-game) | A project that creates a simple turtle race game.<br/> This is learning about handling multiple object and instances in Python, and also talks about Coordinate System.|
| [snake_game](./snake_game) | A project that creates the classic snake game of nokia 3310.<br/> This is learning about inheritance in Python.|
| [pong-game](./pong-game-v2) | A project that recreates the retro pong game.|


_More projects are added over time._

## Getting started

1. Clone the repo:

   ```bash
   git clone https://github.com/rakie1210/python-projects.git
   cd python-projects
   ```

2. Open a project folder:

   ```bash
   cd python-projects
   ```
